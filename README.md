# E-Commerce Revenue & Customer Behavior SQL Analysis
## Project Overview
Tujuan dari analisis ini adalah untuk menggali wawasan mendalam mengenai tren penjualan bulanan, kategori produk dengan performa terbaik, serta melakukan segmentasi pelanggan guna membantu manajemen dan tim pemasaran dalam merumuskan strategi bisnis berbasis data (*data-driven decision making*)

* **Tools yang Digunakan:** Google BigQuery (SQL), Microsoft Excel, Google Looker Studio / Looker (Visualisasi)
* **Dataset:** Public Dataset `bigquery-public-data.thelook_ecommerce`
